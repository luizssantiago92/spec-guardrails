## Summary

Removes Cursor IDE hooks entirely in **4.3.0**. The automatic scope and shell checks that hooks used to trigger remain available — the agent runs `context-guard` and `sandbox` CLI commands at phase boundaries instead.

**Why:** Each edit/shell action spawned short-lived Node processes (especially heavy on Windows with `npx`). Hooks were opt-in since 4.2.0, fail-open under load, and duplicated checks the agent already runs via CLI.

## Changes

- **Deleted:** `lib/cursor-hooks.js`, hook templates under `templates/cursor/`, `test/test_cursor_hooks.test.js`, `docs/guide/Cursor-hooks-and-sandbox.md`
- **Added:** `lib/cursor-hooks-cleanup.js` — idempotent legacy cleanup on every `install`
- **Preserved:** `context-guard` and `sandbox` CLI commands and their libraries unchanged
- **Compatibility:** `--with-cursor-hooks` / `--without-cursor-hooks` accepted as no-op with deprecation warning
- **Docs/skills:** Removed hook sections from hub, elicitation, FAQ, Overview, README; added Migration 4.3 section
